## Context

执行页顶部留白偏多:标题栏(46)→ home 图标(y=54)→ 卡片(y=76)→ 内部状态文字(y=12)/统计行(y=36)。用户澄清后要求:窗口标题栏(加密狗+logo)完全不要动、所有页面常显;蒙层顶部原本有 60px 高光描边带,其底边形成横向分割线把蒙层分割成上下两部分——必须去除;home 图标上移至紧贴标题栏底部;统计卡片与表格统一放进完整圆角半透明毛玻璃蒙层并整体上移至图标下方,内部无独立标题栏或分层容器。动机见 proposal.md「Why」。

## Goals / Non-Goals

**Goals:**

- 窗口标题栏在所有页面保持展示,不做任何改动。
- 执行页蒙层为干净统一的半透明面(关闭顶部高光描边带,无横向分割线),表单页蒙层保持原样。
- home 图标紧贴窗口标题栏底部(约 2px 间隙),执行页顶部保留隐形拖拽区。
- 蒙层与内部内容整体上移(蒙层顶 y=70),减少顶部留白。

**Non-Goals:**

- 不改统计卡片与表格的任何样式/行为。
- 不改表单页布局与毛玻璃、窗口标题栏。

## Decisions

### D1: 标题栏常显不动、home 图标紧贴标题栏底部、蒙层去除顶部高光带(EncryptDogFrame + GlassCardPanel)

用户澄清:"固定的透明标题栏"=蒙层顶部 60px 高光描边带(GlassCardPanel.paintComponent 的 TOP_HIGHLIGHT 圆角描边),其底边在蒙层上形成横向分割线,把蒙层分割成上下两部分;窗口标题栏(加密狗+logo)则完全不要动。执行页 startOperation 关闭蒙层顶部高光带(setTopHighlight(false)),backToForm 恢复 true;窗口标题栏在所有页面常显(移除 setVisible 切换);homeButton 定位 (12, 2),紧贴窗口标题栏底部(2px 间隙);WIDE_CARD_Y = 70(蒙层位于图标下方,图标底 22)。执行页顶部隐形拖拽区由 ProgressPanel 顶部 34px 提供,窗口仍可拖动。

### D2: 蒙层与内容上移(ProgressPanel)

ProgressPanel 内部上移:statusLabel y=10、统计行 statY=32、列表 listY=96;GlassCardPanel 常开毛玻璃渲染(移除 frosted 开关),统计卡片、表头、行条全部直接叠加于蒙层内部,不新增容器或标题栏。

## Risks / Trade-offs

- [图标与蒙层间距] → 图标(12,2,20×20)底边 22,蒙层顶 70,48px 间隙,验收确认视觉密度合适。
- [蒙层上移后列表可视行数] → 蒙层高 = 754 − 70 − 44 = 640,列表可视行数 ≥10 仍满足。

## Migration Plan

纯 GUI 变更,无数据迁移;回滚即恢复无打底形态与旧坐标,不影响功能行为与终端模式。
