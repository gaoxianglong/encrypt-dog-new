# Design: 头部标题块垂直居中

## Context

当前 `EncryptFormPanel` 头部几何（卡片 580×600，分段选择器 y64..100 冻结）：

- 主标题 "Encrypt files"：(30, 14, 400, 34)、26pt 加粗、TEXT_PRIMARY
- 副标题 "Protect your files with local encryption"：(30, 48, 420, 16)、13pt、TEXT_SECONDARY
- 副标题底边 64 与分段选择器顶边 64 齐平（贴边）

动机见 proposal.md - Why。此前头部高度预算为 y12..64（52px），标题块 50px 贴底排布。

## Goals / Non-Goals

**Goals:**

- 标题+副标题作为一个整体（50px 高）在头部容器内垂直居中
- 副标题与分段选择器之间出现明显可见间距
- 分段选择器及其下方全部模块几何零变化

**Non-Goals:**

- 不改字号、颜色、文案与对齐方式
- 不改标题栏（窗口顶部品牌区）与卡片其他区域
- 不触碰终端模式与核心逻辑

## Decisions

### D1. 头部容器定义为卡片顶(0)至分段选择器顶(64)

- 头部容器 = y0..64（64px 高）。标题块 34+16=50px，垂直居中后上下留白各 7px：主标题 (30, 7, 400, 34)、副标题 (30, 41, 420, 16)。
- 块中点 7+25=32 = 容器中点 32，几何上严格居中；副标题底边 57，与切换栏间距 7px。
- 备选方案对比：
  - 仅在 y12..64 内居中：上下留白各 1px，间距不可感知，不满足"明显可见的间距"。
  - 压缩标签高度（标题 34→30、副标题 16→14）在 52px 预算内挤出间距：需改动字号可读性相关布局，收益仅 4px，不值得。
  - 下移分段选择器腾出间距：破坏"下方模块几何零变化"的稳定性约束，拒绝。

### D2. 间距量化

- 间距 = 副标题标签底边 57 与切换栏顶边 64 之差 = 7px（含 13pt 字形内部留白，视觉间距约 10px），肉眼可辨且不浪费垂直空间。

### D3. 实现面

- 仅改 `EncryptFormPanel` 构造函数中两个 JLabel 的 `setBounds` y 值（14→7、48→41），无新组件、无布局管理器变更。

## Risks / Trade-offs

- [标题上移后距卡片顶仅 7px，玻璃高光描边（顶部 60px 弧线）是否干扰] → 高光为装饰性描边非填充，26pt 字形实际起始约 y12，无重叠；截图验证确认。
- [居中判定主观] → 以几何块中点严格等于容器中点为准，可像素验证。
- [回归面] → 切换栏位置不变，下方全部模块零变化；apply 后跑 GUI 冒烟 + 终端回归。

## Migration Plan

纯增量，无数据/格式变化；回滚 = revert 本 change 提交。
