## Context

执行页当前几何(窗口 1200×800,标题栏高 46):home 图标 (12,2,20×20) 紧贴标题栏底部(图标底 22);蒙层 (20,70,1160,640)(顶距图标底 48px);蒙层内内容锚定顶部(statusLabel y=10、统计行 y=32、列表 y=96);蒙层底距内容区底部 44px(版权信息上方)。动机见 proposal.md「Why」。

## Goals / Non-Goals

**Goals:**

- 蒙层顶部上移至紧贴 home 图标下方(2px 间隙),与「标题栏↔图标」的 2px 间距语言一致。
- 蒙层内内容随蒙层整体上移,内部相对布局不变。
- 蒙层底部保持距内容区底部 44px,列表可视行数 ≥10。

**Non-Goals:**

- 不改 ProgressPanel 内部布局坐标。
- 不改窗口标题栏、home 图标位置、蒙层顶部高光带开关、表单页。

## Decisions

### D1: WIDE_CARD_Y 70 → 24(蒙层顶紧贴图标底)

蒙层顶 = 24,图标底 = 22,2px 间隙;蒙层顶绝对 y = 46+24 = 70。与标题栏(46)↔图标(48)的 2px 间隙同语言,顶部留白压缩到最小。

- 备选 A:上移至 40(间隙减半)→ 仍留 18px 死区,与「也往上移动一些」的收紧意图不符,放弃。
- 备选 B:上移至图标下方 0px 或与图标重叠 → 蒙层与图标同层后添加者在上,蒙层会盖住图标,放弃。

### D2: 蒙层底部固定,高度随之增长

底部保持 WIDE_CARD_BOTTOM_GAP=44 不变,蒙层高 640 → 686,多出的 46px 全部给滚动区(可视行数 10 → 约 11)。备选:整体平移保持高度 → 底部出现 46px 死区,视觉不平衡,放弃。

## Risks / Trade-offs

- [图标与蒙层间距过紧] → 2px 与标题栏↔图标间距一致,视觉统一;若验收要求更大间隙,只需调整 WIDE_CARD_Y 单常量。
- [蒙层增高对行布局的影响] → 只扩大滚动区高度,表头/行条/排序逻辑不受影响。

## Migration Plan

纯 GUI 常量变更,无数据迁移;回滚即恢复 WIDE_CARD_Y=70,不影响功能行为与终端模式。
