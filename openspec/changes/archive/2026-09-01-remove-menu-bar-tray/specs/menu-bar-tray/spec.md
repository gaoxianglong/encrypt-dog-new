# menu-bar-tray Spec Delta

## REMOVED Requirements

### Requirement: 托盘守护进程生命周期

**Reason**: 用户决定彻底移除菜单栏托盘功能（.app/dmg 与 jar 形态均不再需要），守护进程与其生命周期管理一并废弃。

**Migration**: 无迁移——功能整体删除，用户继续以 `dog --gui` 或 .app 直接运行 GUI。

#### Scenario: 守护进程不再存在

- **WHEN** 用户以任意形态（jar/.app）启动加密狗
- **THEN** 系统不启动守护进程、不探测或监听任何本地托盘端口，GUI 进程退出即全部退出

### Requirement: 菜单栏图标与菜单

**Reason**: 用户决定彻底移除菜单栏托盘功能，菜单栏图标与 Open/Quit 菜单不再提供。

**Migration**: 无迁移——图标与菜单随守护进程删除。

#### Scenario: 菜单栏无图标

- **WHEN** 用户运行加密狗 GUI（任意形态）
- **THEN** macOS 菜单栏不出现加密狗图标，也不存在 Open/Quit 托盘菜单

### Requirement: 唤醒与单例

**Reason**: 用户决定彻底移除菜单栏托盘功能；二次启动单例（带前台唤醒）属托盘能力的一部分，经用户确认一并删除，回退为托盘引入前行为（二次启动可能开两个窗口）。

**Migration**: 无迁移——单例行为回退至托盘引入前。

#### Scenario: 无单例唤醒

- **WHEN** GUI 已在运行时用户再次以 `--gui` 启动
- **THEN** 新实例正常开新窗口，不唤醒/复用旧窗口（与托盘引入前行为一致）

### Requirement: 退出语义

**Reason**: 用户决定彻底移除菜单栏托盘功能，托盘 Quit 与"关窗图标保留"语义不再存在（GUI 关闭即进程退出，与托盘引入前一致）。

**Migration**: 无迁移。

#### Scenario: 关窗即全退

- **WHEN** 用户点击 GUI 窗口 ✕
- **THEN** 窗口与进程退出，菜单栏无任何加密狗残留图标

### Requirement: 自愈与端口冲突降级

**Reason**: 用户决定彻底移除菜单栏托盘功能，守护自愈与端口降级逻辑随守护进程删除，本地端口 32345/32346 不再使用。

**Migration**: 无迁移——端口与相关逻辑全部移除。

#### Scenario: 端口不再使用

- **WHEN** 加密狗任意形态运行期间
- **THEN** 系统不监听 32345/32346 端口，不存在端口冲突降级与守护自愈逻辑
